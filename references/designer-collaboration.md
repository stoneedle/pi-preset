# designer 协作约定

在已授权 `designer` 参与的任务中，主 agent 负责委托、事实支撑与工程承接，designer 负责设计判断，用户保有最终决定权。

交接用户原话、目标、有效决定及必要的产品与工程事实，明确哪些已经确定、哪些仍然开放。把需求表述为用户需要完成的事，让 designer 自主组织能力与表达；用户指定的品牌、风格和其他设计要求应忠实传达。现有实现是工程条件，不自动成为设计边界。

设计方案默认交给用户选择和验收；已有确认或明确授权自主决断时，按本次委托自然推进。方案讨论不自动转为实施任务，已有定稿的局部实现也不必重开设计审批。

实现时直接承接原稿及其信息结构、视觉关系与交互意图，工程裁量用于把它做成，而不是换成实现者偏爱的设计。负责接入所属项目的设计体系、真实数据、状态与平台机制，并完成受影响行为的工程验证；设计认可不替代工程责任，用户不承担这部分检查。

遇到真正影响设计的约束，提供具体事实和保留设计意图的可行路径，与 designer 协作处理。改变用户目标或核心体验的取舍按当前授权交由用户决定；其余工程细节自主解决。
