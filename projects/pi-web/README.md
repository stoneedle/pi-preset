# pi-web

个人自用的 Pi 手机远程界面，只支持中文。每个 PWA 只连接安装地址对应的电脑，不在应用内添加或切换电脑。手机与电脑控制同一个原生 Pi 会话，默认沿用原工作区和原生聊天记录；显式分叉才创建独立会话。

## 日常使用

- 首页按名称固定排列项目树，会话按创建时间倒序。抽屉点击文件夹才加载并展开会话，不自动切换对话；长按会话可改名、分叉、归档，长按文件夹可归档其中断开的会话，或归档整个文件夹；长按“已归档”图标可归档全部断开会话，覆盖未加载的分页、不受搜索限制，已连接的 Pi 会跳过。单条及整文件夹归档即刻隐藏、后台同步，失败恢复并提示；批量清理断开会话等待服务端复核成功后隐藏，失败整批回滚；保持列表位置，不跳首页或顶部，不停止 Pi、不删除记录。逐条归档至空仍保留文件夹。统一“已归档”入口在抽屉内切换，支持分组、搜索和无限滚动；点一条只恢复该会话并打开，同时让文件夹回到常规列表，其他会话仍归档。在归档目录明确新建会话会让文件夹重新出现，旧归档会话收到回复不会。右滑打开全屏抽屉、左滑返回对话，草稿与阅读位置保留；顶部铃铛切换只看活跃会话（未读、主任务／子任务进行中或待你处理），搜索继续生效，不显示已归档会话。
- 长按会话选择“分叉为新会话”，复制当前活动分支；用户气泡长按菜单选择“从这里分叉”，或点击模型回复下方的 Fork 图标，保留到该消息（含该消息）。成功后直接进入新会话，名称为“原名 · 分支”，独立 UUID 和 JSONL，原会话与草稿不变。分叉不停止原 Pi、不自动发送，首次发送才启动新执行器；仍使用原工作目录，不创建 Git 分支。工具调用中途不能分叉。用户气泡长按也可复制；完整模型回复下方提供复制图标，工具穿插说明的复制图标紧随对应正文，行尾不足时自然换行。复制离线可用，模型正文仍可选字和分享。Pi 没有直接重新生成回复的 RPC，暂不提供“重来”按钮。
- 普通点击发送文字或图片作为当前任务的引导；Pi 正在运行时，长按发送可通过小浮层单独排队，不抢走输入焦点或收起键盘；排队后在输入框上方显示单行摘要，点击可完整阅读，并可逐条取回图文编辑或取消。取回前先撤回，当前草稿独立暂存；已开始投递的消息不能撤回。发送中仅在按钮上显示进度，对话只展示 Pi 的正式消息。失败或未确认是否成功时，输入区上方提供“重新编辑”入口，可展开读取原文、离线保存图片；重新编辑会暂存当前草稿，不覆盖或拼接下一条内容，也不自动重发。接收不代表任务已执行，忽略恢复提示不取消 Pi 中的消息；网页队列由同一 Pi 进程持有，不改动电脑端其他队列项；输入框随换行与自动折行增高，长草稿在框内滚动，发送和停止控件始终可达。原生终端对话框仍在电脑处理。
- 弱网时保留已加载内容，抽屉预加载且持续更新；同页切换会话，返回已访问会话先显示内存内容与草稿，再增量同步；空闲时逐页预取近期打开会话的更多历史，前台通信优先；向上滚动自动提前加载，先显示缓存、不必逐次点按钮。缓存总预算约 64 MiB、单会话自动预取约 8 MiB，后台历史不立即渲染；已展开过的工具和思考正文也能离线再次阅读，更新失败不隐藏已读正文。正文与草稿仅留在标签页内存，刷新清空。阅读位置单独保存在本机：切 App、锁屏或切会话回来停在原处，不跳过新内容；刷新或系统回收后按书签读取附近历史。前台位于末尾时继续跟随，上滑或选字暂停；主动滚回底部、点击向下箭头或普通发送成功才追到最新，排队和失败不跳转。书签只含定位坐标、不含正文或草稿，不跨设备同步。读取自动重试，发送不会自动重放。
- 首页底部单行入口展开为全屏新任务编辑器，默认上次实际发送的项目，也能浏览并选择没有近期会话的已有文件夹；发送才创建会话，关闭保留草稿。输入区内通过同一浮层选择模型、思考强度和速度，Fast 使用闪电图标。标题最多两行；下方固定单行信息条显示项目文件夹（分支）、↑输入／↓输出、CH 和环内上下文百分比，token 统一为 k，上下文超过 70%／90% 时圆环与百分比一起变黄／红；未知显示问号，圆环仅在顶部出现。
- 外观自动跟随系统浅色／深色并实时切换，统一使用系统字体、Lucide 图标和克制的圆角与动效；减少动态效果的系统设置同样生效。
- 输入区和消息中的图片只显示小缩略图，不展示文件名、尺寸说明或下载文字；点击全屏查看后显示名称并可下载原件，待发送图片可单独移除。弱网下只自动加载会话缩略图，不下载整张原图。下载原文件，隔离预览 HTML、Markdown 和相对资源。
- 会话顶部“更多”提供两种分享，不要求选中文字，也不弹选区菜单。“分享已加载上下文”可立即分享本页已加载及后台预取的文字和已读取的工具内容，断网也不等待；“分享完整会话”读取当前分支的全部会话文字和工具输入输出，准备后再分享。均以 TXT 通过系统选择 ChatGPT 等应用，不支持文件分享时可下载后手动添加；不包含图片原件、思考或未发送草稿。
- 在支持的浏览器中启用中文通知。通知只包含会话和状态，不包含回复正文；推送服务接受不等于手机已收到。

会话内容、文件、模型名称和底层错误保留原文，不做自动翻译。界面不含语言选择、语言包或自定义翻译。

## 安装与更新

需要 Pi 1.3.0+、Node.js 22.19+、Go 1.26+、Git 和 GNU Make。Windows 使用 Git Bash；GNU Make 不在 PATH 时，通过 `MAKE` 指定它的路径。远程访问使用已有的 Tailscale。

在本仓库目录执行：

```bash
npm ci --ignore-scripts
pi install .
node scripts/run-lifecycle.mjs install
```

安装入口会先构建前端和 Go 程序，再安装对应平台的程序与登录启动配置。默认地址是 `http://127.0.0.1:31415`。

跨电脑只同步源码与依赖锁文件，在目标电脑执行同一安装入口；不要复制另一台电脑的 `~/.config/pi-web/`、登录启动文件、数据库或原生会话。工具链由目标电脑安装并通过其环境发现，`MAKE` 只作为明确的本机构建覆盖，不在源码中指定 SDK 路径。启动器需要的绝对路径由目标电脑安装时生成，不依赖源码所在目录。

Windows 启动器每次启动读取当前系统、用户环境，PowerShell 模块路径由当前宿主初始化；`~/.config/pi-web/env` 保留令牌、代理和服务设置，不保存 PATH 或 PSModulePath 快照。普通安装即使二进制相同，也会修复启动配置并移除旧快照，但不重启已有服务；修复配置后通过 `/pi-web restart` 应用。原位更新只替换二进制，不改配置、登录态或执行进程。

更新已有安装并保留启动配置：

```bash
PI_WEB_INPLACE_UPDATE=1 node scripts/run-lifecycle.mjs install
```

新版后台 Pi 由独立宿主持有，Go 重启不会停止它的任务。服务更新、Worker 更新、重连和返回前台都不自动刷新页面；需要体验新界面时，点击首页顶部刷新图标或会话顶部“…”菜单中的“刷新界面”。刷新先检查页面可读取，再对当前标签页所有会话及新任务的草稿、附件、待应用设置和未确认内容统一确认丢弃；有在途控制请求时不可刷新，取消或失败继续保留原页面。刷新一个标签页不影响其他标签页，也不停止 Pi。草稿仍只在页面内存中，整页刷新或关闭后不恢复。

扩展代码有变化时，对已打开的 Pi 实例执行 `/reload`。仅更新网页服务不会替换原生实例内已加载的扩展；旧快照未提供累计 usage 时，输入／输出显示问号，而不是估算或显示零。

| Pi 命令 | 用途 |
| --- | --- |
| `/web` | 打开当前会话 |
| `/remote` | 显示 Tailscale HTTPS 地址和二维码 |
| `/pi-web status` | 查看服务状态和地址 |
| `/pi-web start`、`stop`、`restart` | 管理当前服务 |
| `/pi-web token`、`set-token` | 查看或设置访问令牌 |

远程访问前，在 `~/.config/pi-web/env` 中设置稳定的 `PI_WEB_TOKEN`，然后重启服务。保持令牌不变即可保留浏览器登录。iPhone/iPad 通知需要通过主屏幕 PWA 打开，并使用 HTTPS；真机后台和锁屏接收仍需实际检查。

## 应用名称

PWA 安装名称默认只使用当前电脑的主机名，不加 Pi 前缀。手机和 PC 均可通过首页或会话顶部的“更多 → 应用名称”设置覆盖名称；留空并保存恢复主机名。设置保存在当前电脑的 `pi-web.sqlite`，不写源码、环境变量或浏览器偏好，也不随跨电脑分发同步。

保存后更新当前页面的安装元数据，并通过已有实时连接同步其他已打开的页面；不刷新文档、不清除草稿、不改变会话标题，也不重启服务或 Pi。manifest 的安装身份、启动地址和作用域保持不变。已安装的手机图标名称由系统／浏览器更新，可能需要等待或重新添加；应用不能强制桌面立即更名。

## 排查回到 PWA 后的重新加载

诊断元数据自动上传到当前电脑，记录在 `~/.pi/agent/pi-web/diagnostics/browser.jsonl`，无需从手机导出。反馈问题时可直接按时间、设备和页面身份查服务器日志，区分应用主动刷新、浏览器重建页面和会话窗口重新读取。断网或服务重启时暂存待发送元数据，恢复后自动补传；确认接收后删除本地待发送批次。日志不含正文、草稿、图片或令牌，单文件最多 4 MiB，保留当前文件和两份轮转备份。

## 数据与边界

- 原生历史：`~/.pi/agent/sessions/`，由 Pi 写入。
- 共享确认、外观和推送数据：`~/.pi/agent/pi-web.sqlite`。
- 运行地址与锁：`~/.pi/agent/pi-web/pi-web-state.json`。
- 独立后台宿主注册与诊断：`~/.pi/agent/pi-web/workers/`。
- 手机页面诊断：`~/.pi/agent/pi-web/diagnostics/browser*.jsonl`。
- 登录与启动环境：`~/.config/pi-web/`。
- 原生命名配置：`~/.pi/agent/extension-data/pi-title-glyphs/config.json`。
- 项目记忆：`~/.pi/agent/pi-web-memory.sqlite`，使用随包安装的 `memory` 技能。

`PI_CODING_AGENT_DIR` 可以指定独立的 Pi 数据目录。浏览历史不会启动执行器；明确新建或向未运行的会话发送消息时，才静默创建后台 worker，无需手动恢复连接。同一会话最多一个受管理的 worker；优先复用已有终端，网络断开不另开实例。确认原进程退出后，下一次发送按原生 resume 打开同一 UUID 与 JSONL，不自动重放旧任务，也不把仍打开的旧实例升格接管。历史会话未运行时也能先选模型、强度与速度，发送前再应用。

Fast 的可选速度与当前状态由原生模式拥有者提供，网页通过版本化会话接口设置并验证结果，不复制模型适用规则、不调用会写全局设置的 toggle 命令。选择记录在原生会话中，恢复该会话时仍有效，不影响其他会话。已连接实例未安装对应接口时禁用速度控制；尚未运行的会话可以预选，发送时由原生接口校验，不支持则保留草稿并报错。新任务可选择跟随 Pi。当前本地接口的维护入口是 `node scripts/enable-fast-state.mjs`；安装或升级接口使用 `--apply`，只接受已审阅的源码指纹，保留备份并拒绝未知版本。

## 开发与验证

```bash
make build       # 先构建前端，再构建嵌入它的 Go 程序
make test        # 前端、扩展、记忆、Go 和安装器测试
make check       # lint、格式、knip、测试、前端构建和 vet
make e2e-setup   # 首次安装浏览器测试依赖
make e2e         # 原生集成和七组浏览器/设备模拟
```

不能只运行 `go build`：程序嵌入的是当前 `web/dist`。测试使用独立临时数据和进程，不接管日常浏览器、服务或会话。

实现约束见 [AGENTS.md](AGENTS.md)，模块职责见 [架构](docs/architecture.md)，测试入口见 [测试](docs/testing.md)。不再维护文档站、营销页面、公开发布流程或多语言副本。
