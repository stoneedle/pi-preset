# 测试

## 入口

```bash
make check       # 格式、lint、knip、前端/扩展/记忆/Go/安装器测试、前端构建、vet
make build       # 前端与嵌入它的 Go 程序
make e2e-setup   # 首次安装 Playwright 和三种浏览器
make e2e         # 构建、原生集成、生产前端浏览器矩阵
```

直接运行浏览器测试前先构建：

```bash
make build e2e-stub
cd e2e
npx playwright test --project="Mobile Chrome" --workers=1
npx playwright test --workers=2
```

需要并行保留其他构建实例时，可用 `make build BINARY=.dev/pi-web-fork.exe` 构建独立产物，并设置 `PI_WEB_E2E_BINARY` 为其绝对路径后运行测试；不覆盖被其他进程占用的二进制。

测试不得启动、停止或清理用户日常服务与浏览器。修改代码后的实际部署使用已有安装/重启入口，与临时测试服务分开。

`make install-test` 包含隔离 HOME 下的 Unix 安装／卸载回归，以及 Windows 上的 PowerShell 安装集成：覆盖 LF／CRLF、含中文／空格／单引号的迁移目录、已有令牌与 UTF-8 配置、相同二进制的配置修复、启动时读取当前 Windows 环境，以及原位更新不改配置。Windows 用例拦截进程和启动注册操作，不修改真实服务；生命周期用例在临时目录构建 Go 工具替身，验证 Git Bash 构建环境不泄漏、PowerShell 宿主状态不继承。非 Windows 平台跳过 Windows 用例。

## 隔离与范围

`e2e/lib/test.ts` 为每个 Playwright worker 在系统临时目录创建独立的 `PI_CODING_AGENT_DIR`，复制脱敏会话，在空闲回环端口启动生产二进制，并禁用测试实例的鉴权和 Tailscale 配置。地址和目录通过同一份 worker fixture 提供，不经进程环境共享，也不共用 `server.json` 或固定会话目录。worker 结束即停止自己的 Go 和独立测试宿主、删除临时目录，避免整套浏览器矩阵积累数十个五小时空闲执行器及跨项目数据；并行 worker 不互相清理。需要鉴权的用例另启隔离实例。浏览器由 `e2e/lib/browser.mjs` 创建独立 BrowserServer，断言结束后强制关闭该测试实例的进程树，避免 WebKit 在 Service Worker／SSE 优雅退出阶段无限等待；不连接日常浏览器。测试只关闭自己的进程树和浏览器 Profile，不改提交的 fixtures。

浏览器矩阵使用 `lib/stub-pi/pi` 模拟确定性原生 RPC 提供方；Windows 的 `make e2e-stub` 生成对应启动程序。它写真实格式 JSONL，通过鉴权快照订阅提供状态，不创建活动心跳文件。静默运行保持连接，关闭套接字才产生未知状态。

| 项目 | 引擎 | 宽度 |
| --- | --- | --- |
| Desktop Chrome | Chromium | 1280 |
| Desktop Firefox | Firefox | 1280 |
| Desktop Safari | WebKit | 1280 |
| Mobile Chrome / Pixel 5 | Chromium | 393 |
| Mobile Safari / iPhone 13 | WebKit | 390 |
| iPad | WebKit | 810 |
| iPad landscape | WebKit | 约 1080 |

这是设备模拟，不等于真机或 Safari.app。维持真实窄屏配置；工具行另检查 360px、320px 和实际设备宽度。键盘通过缩小 visual viewport 而不改变布局宽度模拟，仍需实际设备确认 OS 键盘行为。

- `retention.spec.ts`：分支／历史重置竞态直接触发按钮以固定一次显式读取，避免 Playwright 为点击而滚动到按钮时先触发自动加载、随后点击又读一页；仍保留精确分页断言，真实滚动由 `history.spec.ts` 覆盖，竞态失败时附上隔离服务器中不含正文的诊断 JSON；发送回执丢失、首次正文迟到且同文／同数量不同图片时，输入区的恢复入口仍保留；320px 键盘缩小下展开原文、离线下载原图片、取消／确认忽略与下一份草稿保留；已加载工具／思考跨导航离线展开且不重取；历史重置与在途空增量、连续分支切换、旧重置迟到与后续读取失败均不清空或缩减已读窗口；连续新增时较慢的有效增量仍逐步显示，不等执行静默；工具结果状态相同但原生结果身份变化时更新正文，旧响应不覆盖新正文，失败保留旧正文并可重试。
- `drafts.spec.ts`：晚到回执不清空编辑后又变成同文的草稿；新任务首条发送期间新增的文字与图片交接到目标会话，不藏在关闭的编辑器里；用户已导航离开时，迟到回执不抢回路由；新任务失败恢复入口跨关闭重开保留，并随“打开会话继续”完整交接，重新编辑不覆盖下一条图文。
- `refresh.spec.ts`：首次 PWA 安装后 SSE 连续可用且不刷新；首页／会话顶部的唯一刷新动作、确认丢弃与取消保留、HTML 预检期间的新输入确认、预检单飞及期间新控制阻止导航、临时 502 保留页面，以及无预缓存时真实 Mermaid 加载失败不刷新、不关闭新任务编辑器且不产生额外刷新按钮。
- `diagnostics.spec.ts`：直接检查隔离服务器的 JSONL，验证隐藏／离线／返回前台后保留同一文档、草稿和增量游标，自动上报无正文／草稿、跨刷新关联、手动刷新原因；接收失败跨文档补传、接收确认后清理待发送批次、浏览器拒绝存储时仍在线上报、320px 离线编辑与有界队列、没有导出入口。另验证接收接口鉴权、Origin、元数据白名单、大小上限、重复批次去重、真实文件轮转，以及日志磁盘故障不影响页面。`e2e/lib/diagnostics.ts` 是浏览器及原生集成共用的服务器日志读取入口。生命周期模拟不等同于手机 OS 回收，真机偶发问题查服务器实际日志判断。
- `push.spec.ts`：真实平台能力限制与受控订阅交互，中文通知仅含会话与状态、不展示电脑名称或地址，无需上传模板，测试通知接受不冒充设备到达；授权无响应和推送服务悬挂时显示当前步骤、超时恢复操作，迟到结果不自动提交，320px 小视口可显式重试；已有活动 Worker 时不因注册检查悬挂而阻塞订阅；已有有效订阅但服务端记录缺失时补存而不注销重连，密钥不符／浏览器到期／服务端过期时仍重建；停止等待、关闭重开和离线立即释放控件，迟到结果不保存，显式重试共享未结束的浏览器连接。Chromium 额外通过 DevTools 注入真实 Worker push 事件；其他引擎跳过该注入分支但保留能力/UI 用例。

`app-name.spec.ts` 覆盖默认主机名、公开 manifest 与鉴权登录页的安全转义、安装身份不变、手机／PC 真实双页面实时同步、改名与恢复默认不刷新或丢弃会话草稿、服务重启持久化与机器隔离、320px 键盘高度下编辑长名称、取消／网络失败不重放、迟到回执排序，以及真实 SQLite 写入失败不提前更新名称。

`reading.spec.ts` 覆盖旧末尾离开后后台新增仍停原处、长回复与键盘／选区布局、工具正文刷新恢复并仅补取目标块、刷新从深层书签直接读取有界窗口而非逐页扫描、不持久化正文／草稿、后续前向分页与显式跳最新、失效分支回退共同前文、消息删除／变空后回到可读前文，以及失败／排队不跳、普通发送成功才恢复并持续跟随。书签恢复检查实际可视段落与偏移，而非只检查 scrollTop。

## 原生集成

`make e2e` 在浏览器矩阵之前串行运行 `e2e/native/*.test.mjs`，避免多个真实 Pi 启动、前端二次构建和浏览器进程争抢资源，使宿主退休等短时序断言失真；单个用例内要求的多原生实例并发仍保留：

- `project-options.test.mjs`：真实 Pi 模型目录与项目配置读取、能力级别与目录浏览；新任务与休眠会话的全局／已信任项目／`.agents`／显式路径／包技能及包筛选，未信任或明确拒绝的项目不显示受保护技能，读取不改信任决定；技能发现不执行扩展、不安装包，不创建原生会话／worker、不泄露凭据、不改写用户设置。
- `fork-storage.test.mjs`：真实 SDK 与生产 Go 分叉路径，图文原件、工具、思考、压缩、标签和节点模型／强度／扩展记录保留，排除其他支线、不改原文件、原子发布与临时目录清理。
- `background-worker.test.mjs`：真实已安装 Pi CLI，手机被动打开历史、首条消息前选模型／强度且不启动进程、首次发送使用所选模型、后续复用 PID；实际终止该隔离 worker 后静默原生 resume，保留原 UUID、JSONL 和已保存答案，不创建恢复副本；另验证新任务首次发送前补全已信任项目技能、发送 `/skill:` 后模型实际收到技能指令与参数，仍复用同一执行器；新建独立原生进程、手机首条消息写入首句名及唯一模型摘要名、后续消息不重命名和人工改名同步，以及消息菜单分叉后首次发送启动独立 Pi、源 PID 与 JSONL 不变。
- `process-lifecycle.test.mjs`：独立 OS Pi 进程、原生 SQLite 并发写、实际崩溃/重启、无执行器的历史确认、扩展重载和原生待处理对话框身份。
- `same-instance.test.mjs`：真实 SDK/资源加载器、唯一扩展入口、原生引导和 follow-up 持久化、网页待发送队列逐条取回／取消与实际执行边界、大于普通控制回执上限的图片原件取回、停止及扩展重载保留队列身份、已执行项撤回拒绝、鉴权 Go 与手机界面、图文投递、状态、共享确认、分支返回、真实活跃叶节点分叉与运行中分叉不停止源实例、原文件/图片、预览隔离和推送凭据。
- `push-worker.test.mjs`：生产 Worker 通知模块的持久去重、重排抑制、精确关闭、点击路由和无语言模板的续订。
- `worker-host.test.mjs`：真实独立宿主与 RPC 管道，连续空闲、普通查询不续期、未知子任务／断线打断计时及未完成控制请求保护。
- `upgrade.test.mjs`：两个真实构建、鉴权 Go 和真实 Pi，393px Chromium/WebKit 验证同端口更新与回滚不替换已有页面，手动刷新才加载新界面；当前页面受旧 Worker 控制且新版已 installed/waiting 时不再额外完整加载，旧／新哈希 CSS 在 Go 停止后均可读取；在途控制禁止刷新、原生与宿主 PID 不变、不重放、标签页彼此独立，以及只缓存静态资源、诊断仅有 manual 刷新原因。
- `draft-refresh.test.mjs`：两个真实构建与同端口替换，393px Chromium/WebKit 验证另一标签页可独立手动加载新版，新任务长文本／图片、其他会话草稿和当前阅读文档均保留，320px 键盘缩小仍可编辑发送且真实 SSE 连续；取消手动刷新保留全部内容，确认才丢弃当前标签页内所有草稿；HTTP accepted、503 和下一份草稿均遵循本地刷新确认，在途控制禁止刷新、不重放、不因清理草稿自动导航。

模型适配器确定性且离线，不调用商业模型；原生进程、SDK、Go、SQLite 和生产界面都是真实的。`make check` 另运行 `tests/native/` 中的命名、生命周期、原生确认和会话速度设置协议测试；`title-reload.test.ts` 在隔离副本中更新图标源码后重载同一真实 Pi 实例，检查标题立即采用新图标，不依赖重启；确认成功结算收据不会被已读或分支回访改写，速度变更不制造模型消息；旧 peer 不再在 owner 离开后自动注册。Go 生命周期测试覆盖并发单飞、失败不重放，以及注册丢失但 PID 仍存活时不替换；连续空闲回收由独立宿主集成验证。

需要验证实际安装的子任务提供方时，显式传入本地包路径：

```bash
node e2e/integration/subagents.test.mjs /absolute/path/to/pi-subagents
```

它创建隔离的真实子进程与本地模型端点，检查重载、成功/失败终态、候选依赖与错误完成通知抑制，不读取个人模型配置。

实际 Fast 拥有者的独立集成入口：

```bash
node e2e/integration/fast.test.mjs /absolute/path/to/pi-codex-fast
```

使用隔离副本应用经过指纹验证的接口，检查标准→快速、各速度能力、两个真实原生会话的隔离、恢复后的选择、全局设置不变和无模型请求，不改测试所传包的源码。

## 长会话性能

```bash
node e2e/performance/long-session.mjs \
  --session /absolute/path/to/native.jsonl \
  --baseline /absolute/path/to/chinese-ui-baseline/pi-web \
  --output .dev/traffic-comparison.json
```

选择真实语料和同属中文界面的基线构建。工具验证原始语料哈希，在临时真实原生运行时中重放，并用独立鉴权 Go 服务、Profile、回环代理和窄屏进行比较。代理统计整个来源的响应字节，检查未点击的折叠正文与图片原件没有泄漏（允许独立的小缩略图请求）、普通正文保持完整，并覆盖空闲、更新突发、重连和历史追加。不报告私有正文或令牌，也不把本地 HTTP 测量当成物理手机/Tailscale 的结果。
