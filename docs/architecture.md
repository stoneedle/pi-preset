# 架构

## 职责与交接

| 位置 | 职责 |
| --- | --- |
| `.pi/extensions/index.ts` | 唯一原生扩展入口，管理会话生命周期 |
| `.pi/extensions/lib/session-state.ts` | 原生活动、结果、子任务和确认状态的唯一投影 |
| `.pi/extensions/lib/receipts.ts` | 原生 SQLite 结果确认和通知事件 |
| `.pi/extensions/lib/remote.ts` | 同一 Pi 实例中的鉴权控制与快照订阅 |
| `.pi/extensions/lib/title/` | 原生命名、可选摘要、终端标题与焦点观察 |
| `.pi/extensions/lib/fast-state.ts` | 查询原生 Fast 能力与状态，并桥接会话级设置 |
| `internal/app` | 监听、鉴权、Tailscale、嵌入资源和进程生命周期 |
| `internal/sessions` | 原生 JSONL 索引、活动分支、消息窗口和按需正文 |
| `internal/server` | 浏览器接口、原生 owner 观察、共享确认、附件和通知 |
| `internal/workers`、`internal/rpc` | 明确新建或继续会话时使用的后台 Pi worker |
| `web/src/RemoteRouter.svelte` | 同源首页/会话链接和浏览器前进后退，不重新下载文档 |
| `web/src/routes/RemoteApp.svelte` | 唯一中文会话列表与对话界面 |
| `web/src/remote-cache.js` | 有界的当前标签页内存视图缓存，不写浏览器持久存储 |
| `web/src/remote-drafts.svelte.js` | 每个会话唯一的草稿、附件与发送中状态，回执跨导航仍作用于同一份状态 |
| `web/src/remote-api.js`、`remote-events.js` | 请求截止时间、只读重试、刷新合并及 SSE 传输恢复 |
| `web/src/components/SessionList.svelte` | 首页和会话抽屉共用的搜索、分页与全局运行状态订阅 |
| `web/src/components/NewTask.svelte`、`ProjectPicker.svelte` | 全屏新任务草稿与已有目录选择，不在编辑期间创建会话 |
| `web/src/components/RemoteComposer.svelte`、`ModelPicker.svelte` | 会话与新任务共用的输入、附件及模型／强度／速度浮层 |
| `internal/rpc/project_options.mjs` | 仅用 Pi 的模型目录与设置 API 读取新任务选项，不创建 AgentSession 或 worker |
| `web/src/components/` | 工具/思考、图片、主机切换和通知交互 |

Pi 拥有执行、队列、工具、名称和记录。子任务提供方拥有子任务事实；只有 `SessionState` 对这些公开事实进行协调，标题、Go 和浏览器不另行推断运行状态。

## 阅读、更新与回复

1. Go 返回不含会话内容的 HTML 壳和带内容哈希的 JavaScript/CSS。`main.js` 挂载同源路由，再按会话身份挂载唯一中文界面，没有语言加载或翻译层。
2. `/api/session` 返回最近消息窗口，`/api/status` 与 SSE 提供独立的运行快照。普通正文完整返回；工具和思考只带有界摘要，图片不提前下载。
3. 点击展开时分别请求 `/api/session/block` 或 `/api/session/image`。思考没有可读正文时不产生空展开项；工具摘要包括 `codemode` 的 `code` 输入。跳过的块保持原生索引不变。
4. 前台进入或返回会话，通过 `/api/session/acknowledge` 确认当前已知的精确结果，不必等待正文下载。后台消息、通知到达和会话列表浏览不会确认结果。
5. 原生 JSONL 变化经过监听器防抖，通过 SSE 发送刷新提示。浏览器单飞合并请求，使用 `after` 增量更新稳定消息 ID；`before` 加载历史并保留视口锚点。分支重置使迟到的历史响应失效。
6. 发送经过 Go 鉴权，转给已注册的同一原生 owner，再调用 Pi 的公开消息接口。手机消息只支持引导：原生 owner 固定 `deliverAs: steer`，后台 RPC 的运行中消息固定 `streamingBehavior: steer`；表单和内部消息对象均没有投递方式字段。收到 accepted 只表示已交给 Pi，不代表模型已处理。

首页和抽屉按原生会话头的完整项目路径分组，不合并不同父目录下的同名文件夹，但不展示绝对路径。项目按名称自然排序并以路径作稳定的同名次序，头部显示总会话数、最近真实发言／输出距今天数与聚合未读标记。未读聚合覆盖未加载会话，确认记录按各会话当前结果身份批量读取；完成／未读变化合并触发列表同步，分页外的完成会话也能及时置顶，普通工具状态变化不反复重载。会话按创建时间与原生成功完成时间中的较新者排序，不再使用随工具调用改变的 LastActivity；原生收据的 completed_at 只在首次成功结算时写入，已读、重连、分支回访和失败不会改写。旧收据没有完成时刻时不补造时间。初次返回所有项目头与有界会话列表，每个项目独立加载更多；普通浏览记住当前主机的折叠状态，搜索自动展开匹配项目且不覆盖普通折叠偏好。

首页底部仅有单行新任务入口，点击后同步挂载全屏编辑器并聚焦输入，模型、思考与速度只在完整输入区出现。项目选择器浏览当前主机上的已有目录，不创建目录，不限于近期会话。模型选项通过 Pi 自身的 ModelRuntime、SettingsManager 与能力函数读取，不创建执行器；注册于扩展、尚不可知的默认模型仍交给 Pi 决定，不替换成网页猜测的回退模型。首次发送才创建会话、连接 worker、应用所选设置并提交图文；设置或发送失败保留草稿与已创建会话身份，转入该会话可继续处理。新任务与已有会话共用输入组件；显式模型／强度选择由草稿持有，不被迟到的默认值覆盖，发送时冻结本次设置；草稿不落浏览器持久存储；最后实际发送的项目是独立的当前主机偏好。

会话页左上角打开左侧模态抽屉，不离开当前对话；搜索、分页、未读和运行状态复用首页会话列表。对话挂载时以低优先级预加载列表并订阅全局 SSE；抽屉关闭只隐藏，不销毁列表、搜索或订阅，因此再次打开不等待网络，对话也继续更新。全局列表刷新合并并限频，状态增量直接更新已加载行。点击当前会话、遮罩、关闭按钮或 Escape 收起抽屉，保留草稿、附件和阅读位置；选择其他会话才导航。浏览抽屉不确认对话中新到达的结果，收起后恢复精确已读确认。

界面以无边框内容流呈现，没有重复角色标题或消息分隔线。思考和工具使用 28px 紧凑行、较小字号和次要色，正文与 Commentary 使用正文色、正文行高和独立留白，形成主次。工具名、单行摘要、状态图标和展开箭头在窄屏内保持横向排列。展开信息、长草稿、技能候选和多图片不应把发送/停止控件挤出可视区域。输入框根据内容、自动折行和宽度变化自动增高或收缩，达到随可视高度收紧的上限后框内滚动；发送清空和技能补全也同步高度。连接提示、技能候选和附件处于独立可收缩辅助区，不得挤走输入框与发送/停止控件。正在阅读历史的人不能因更新、输入框增高或键盘变化被强制拉到底部。

## 弱网与本地交互

同源首页和会话链接使用客户端导航；跨主机、下载和预览仍使用原生链接。访问过的会话先显示内存中的正文和阅读位置，再用原游标增量同步。视图缓存最多八项、合计约 8 MiB；未发送的文字、图片与发送中状态单独按会话保留，不随视图淘汰；导航期间收到回执仍只清理本次提交的内容，不能抹去新写的草稿。内容不落 localStorage、IndexedDB 或 Service Worker，刷新页面后重新读取。缓存不恢复执行状态或控制权限，只有新取得的原生快照可以恢复它们。

读取请求每次包含正文下载在内限时十二秒；网络错误和可重试 HTTP 状态先做两次带抖动的退避重试，刷新协调器在持续故障时继续有上限地退避。已有正文和列表不因失败清空，切换会话会取消旧刷新。鉴权和确定性业务错误不自动重试。发送与其他控制请求限时四十五秒，绝不由请求层自动重放；丢失响应时保留草稿并明确结果尚未确认。发送错误和回执由会话输入状态持有，正文刷新成功不能将它们清除；读取错误只由成功读取清除。

浏览器 SSE 每十五秒接收传输心跳，四十五秒无任何事件时重建连接；离线立即使运行状态未知，网络恢复或返回前台时恢复失效连接，并补取正文和状态。该截止时间只判断传输可用性，不推断 Pi 是否完成；重连及迟到 HTTP 仍遵循运行状态观察代次。

## 原生记录与窗口

`Cache.OpenContent` 缓存身份、父链、字节范围、角色、结果和工具引用，不缓存正文。冷索引仍读取并验证 JSONL，但不构建历史正文、思考、工具参数或图片对象。只有没有原生名称时才读取有界的首条用户前缀作为回退名称。

空文本与无可读正文的思考不投影为显示块，保留其余原生块索引；Markdown 入口也允许缺失文本，避免单条空记录导致整个页面白屏。窗口沿原生 `parentId` 选择活动分支，目标是 30 条消息、约 64 KiB；单条长回复保持完整，预算不是正文截断器。工具结果更新对应调用，不另造助手消息。记录替换、截断或原生叶节点尚未落盘时返回可重试错误，而不是拼接错误内容。已连接运行时的空叶节点代表已知空根，不能与没有运行时覆盖混淆。

文件监听只负责内容失效，不代表执行状态。新项目目录中的首个已存在会话也必须能触发更新。监听不可用时才使用内容轮询。

## 运行状态与确认

Go 通过原生 owner 文件定位地址，并保持一个经过鉴权的快照订阅。快照首先原子提供当前状态，再推送修订。浏览器与 Go 不通过文件时间、标题字符串、输出静默或活动文件判断执行是否完成；没有活动文件心跳、运行状态 TTL 或浏览器状态轮询。

owner 文件包含 PID、端口、原生 UUID 和随机令牌，控制时校验原生会话身份。连接关闭立即变为未知。HTTP 与 SSE 共用带观察代次的合并规则，旧 HTTP 响应不能覆盖更新的 SSE 事实，断线前开始的响应不能重新恢复“在线”状态。

SQLite 中的确认键是原生会话 UUID 与精确结果 ID，不是时间水位。Pi 可以在 Go 停止时独立写入确认；Go 可以在没有执行器时确认历史结果。切换分支、重连或重复快照不会制造新的完成结果，也不能用旧确认清除新结果。

主运行在 `agent_settled` 结束，而不是中间的 `agent_end`。完成候选必须对应本次产生的新可读结果，并绑定本次观察到的子任务身份。只有原生 idle、已知零活动子任务，以及相关提供方明确成功的终态证据同时成立，才允许完成；失败/停止会取消候选，缺少证据保持未知。候选与依赖在扩展重载时保留，不另建子任务执行账本。

原生阻塞对话框以其原始身份保留至原客户端处理。扩展重载不伪造确认，也不把未解决对话框当成空闲。

## Worker 与进程

浏览、状态查询、下载和确认均不创建 worker。明确继续会话时，先检查现有终端 owner；`workers.Manager` 单飞创建并复用一个 `pi --mode rpc --session` 进程。崩溃后淘汰，下一次明确继续才替换。十分钟空闲回收要求已连接的原生 idle 和已知零子任务。

同一会话的第二个原生实例只作为 peer。owner 离开后，peer 可以竞争注册并发布自己的状态；发现地址不代表推断活动，也不会启动另一个执行器。

## 附件和预览

本地文件引用按原生会话 CWD 解析，下载返回原字节和附件响应头。HTML 和 Markdown 只有明确预览时才创建随机、只读、短期能力地址，`os.Root` 限制在文档目录内并处理符号链接。

预览 iframe 使用不含 `allow-same-origin` 的沙箱，CSP 限制控制接口、表单外发和资源范围。相对 HTML 模块、CSS、JSON 与 Markdown 资源在该能力范围内读取，不共享 Pi 控制凭据。关闭、重新加载、过期、驱逐或 Go 重启使旧能力失效。私有 Pi 目录不是预览根。

## 通知

通知弹窗由页面顶层唯一实例持有，入口放在首页或会话信息菜单，打开时先关闭菜单，弹窗不受折叠与菜单项重绘影响。`push.go` 负责 VAPID、加密投递、去重和持久重试；`push_http.go` 负责订阅接口。服务端固定生成中文通知，浏览器只提交订阅和续订信息，不上传或持久化翻译模板。升级时只清理订阅 JSON 中的旧模板，保留端点、密钥、登录和待发送事件。

只对经过验证的未读完成结果或明确待处理身份通知。运行中、后台、未知、取消和失败不能制造成功通知。身份由原生会话 UUID、结果/待处理 ID 决定，重连与分支返回不重复发送。发送前和展示前检查结果仍有效；收到或关闭通知不写已读。

VAPID 私钥保存在 SQLite，不向浏览器返回，也不在升级时替换。Apple、Google、Mozilla 推送端点采用 HTTPS 白名单并禁止跟随重定向。消息只含主机、原生名称、身份与状态，不含正文或原生对话框文本。

Service Worker 不缓存会话，只保存去重和续订元数据。点击通知聚焦精确会话，不覆盖其他会话的草稿。仅关闭精确已确认结果的通知，订阅更换时迁移待投递事件。服务接受不等于设备实际收到。

## Fast 与命名

Fast 的项目/命令行/持久设置优先级、实时切换和模型适用性属于模式拥有者。网页使用版本 2 事件：`pi-codex-fast:query` 查询、`pi-codex-fast:state` 回应、`pi-codex-fast:set` 会话设置、`pi-codex-fast:changed` 失效通知。`availableModes` 表示各目标模式的能力，不拿当前模式是否生效代替它；只在目标不同时设置，拥有者写原生会话 custom entry 并在恢复时读取，不修改全局默认，也不向模型提交假命令。原来的终端 toggle 命令仍保有其原生持久设置行为。请求/回应必须同步匹配版本、requestId 和当前模型；缺失、未初始化、多个冲突回应或异步回应都保持未知，不复制允许列表或推断服务等级。

`scripts/enable-fast-state.mjs` 仅为已审阅的本地 0.1.11 源码安装这一接口，默认 dry-run；从原版或已知旧接口单向升级为同一版本 2 输出，校验目标指纹，备份后原子替换，拒绝未知修改。模型名单和服务等级规则仍只存在于原生拥有者，不在项目中复制。

标题实现来自 `pi-title-glyphs`，原 MIT 许可保留在模块目录。命名沿用原配置路径及 `PI_TITLE_GLYPHS_*` 环境变量。已保存名称不再读取开场正文；标题追加游标只读取新增命名元数据。过期模型摘要不能覆盖另一实例的手动改名。

## 外观

`theme.css` 是浅深色的唯一色板，使用 prefers-color-scheme 自动跟随系统；启动脚本只同步浏览器 theme-color，不再恢复旧主题或加载自定义主题覆盖。应用与令牌登录页共享色板。系统字体作为默认，已有明确字体偏好仍保留。输入区、浮层和抽屉使用统一的圆角、阴影与 Lucide 图标；动效遵守 prefers-reduced-motion。

## 鉴权与安装

令牌 cookie、请求头和登录表单沿用现有协议。浏览器危险请求校验 Origin；无令牌本地访问校验 Host，防止 DNS 重绑定。非回环监听需要令牌；只有启用令牌时才配置 Tailscale Serve。

平台安装、登录启动与重启复用 `scripts/run-lifecycle.mjs`、现有安装器和平台服务管理/启动器。源码更新必须安装本次构建，不能仅因版本字符串未变就跳过。日常数据与配置保留，重启后验证监听、鉴权和前端产物。自动化操作权限由 [AGENTS.md](../AGENTS.md#服务) 统一规定。
