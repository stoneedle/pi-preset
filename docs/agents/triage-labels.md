# Triage Labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for necessary information or a user decision |
| `ready-for-agent` | `ready-for-agent` | Specified sufficiently for an agent to implement |
| `ready-for-human` | `ready-for-human` | Requires human implementation or external action |
| `wontfix` | `wontfix` | Will not be actioned |

Use the mapped label whenever a skill refers to a triage role.

Remove conflicting old triage labels when changing state. Record the reason before closing an Issue as `wontfix`.

`ready-for-agent` describes implementation readiness, not completed implementation, deployment, or acceptance.
